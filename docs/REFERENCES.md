# FORMA — References

These references define the design standard and visual vocabulary.

They are not templates to copy.

For each reference, focus only on the explicitly listed traits.

---

## 1. SemiCreative

Reference:
https://onepagelove.com/semicreative

Use it for:
- whitespace;
- disciplined grid;
- clean editorial feeling;
- typography-led composition;
- restraint;
- long-scroll pacing.

Do NOT copy:
- exact section order;
- exact typography;
- exact spacing values;
- exact content structure.

Question to ask while reviewing:

> How does the page feel premium with relatively few decorative UI elements?

---

## 2. Home Société

Reference:
https://onepagelove.com/home-societe

Additional article:
https://www.commarts.com/webpicks/home-societe

Use it for:
- editorial storytelling;
- visual rhythm;
- large imagery;
- typography as part of the interface;
- distinct desktop/mobile thinking;
- motion inspiration.

Do NOT reproduce:
- full-site horizontal navigation;
- heavy motion patterns;
- exact brand presentation.

Question to ask while reviewing:

> How are photography and typography sequenced to create a premium narrative?

---

## 3. Baden Concept

Reference:
https://baden-concept.com/

Use it for:
- commercial clarity;
- custom furniture / kitchen business context;
- services;
- process;
- portfolio;
- FAQ;
- contact logic;
- credible CTA placement.

Do NOT copy:
- branding;
- exact page blocks;
- text;
- imagery;
- visual treatment.

Question to ask while reviewing:

> Which sections make a visually strong furniture website commercially useful rather than purely artistic?

## Reference extraction rules for Codex

When using these references:

1. Do not copy HTML/CSS or page structure directly.
2. Do not recreate a screenshot pixel-for-pixel.
3. Extract principles only.
4. Prefer the approved project brief when a reference conflicts with it.
5. If a reference requires heavy technical complexity, simplify it.
6. FORMA must remain its own visual identity.

The intended combination is:

**SemiCreative discipline**
+
**Home Société editorial richness**
+
**Baden Concept commercial usefulness**
