# FORMA — Visual Direction

## 1. Visual concept

FORMA should feel like a modern editorial interior/furniture brand rather than a generic small-business template.

Target feeling:

**warm editorial premium**

The site should feel:
- calm;
- architectural;
- tactile;
- spacious;
- considered;
- visually expensive without luxury clichés.

## 2. Reference DNA

Primary reference mix:

- **45% SemiCreative**
  - whitespace;
  - clean grid;
  - restraint;
  - typography-led composition.

- **35% Home Société**
  - editorial rhythm;
  - photography-first storytelling;
  - large visual moments;
  - character and motion inspiration.

- **20% Baden Concept**
  - commercial clarity;
  - real business sections;
  - clear CTA logic;
  - practical service structure.

Do not copy any reference 1:1.

The goal is to extract design grammar, not layout duplication.

## 3. Design grammar

Use:
- editorial grid;
- oversized type;
- strong photography;
- asymmetry with control;
- restrained UI;
- thin rules and subtle separators;
- large sections;
- generous whitespace;
- low card density.

Avoid:
- repeated rounded cards;
- generic icon grids;
- SaaS dashboard patterns;
- excessive badges;
- gradient-heavy presentation;
- glassmorphism;
- bright tech-blue or neon accents;
- decorative fake statistics.

## 4. Palette

Suggested direction:

### Background
Warm ivory / limestone.

Example starting point:

`#F1EEE8`

### Primary text
Near-black.

Example:

`#191815`

### Deep secondary
Warm dark brown / graphite.

Example:

`#302C27`

### Accent
Muted olive / bronze.

Examples:

`#726B56`
or
`#6A6655`

These are starting references, not mandatory final values.

The final palette should maintain strong readability.

## 5. Typography

Use a deliberate serif + grotesk pairing.

### Display / editorial serif

Possible direction:
- Instrument Serif;
- DM Serif Display;
- Cormorant Garamond;
- another modern editorial serif with good Cyrillic support.

The selected typeface must support Cyrillic reliably if Russian text is used.

### UI / body grotesk

Possible direction:
- Inter;
- Manrope;
- Geist-like neutral grotesk;
- system sans if necessary.

Typography should create hierarchy through:
- size;
- whitespace;
- line length;
- contrast in families;
- controlled line breaks.

Avoid overusing heavy font weights.

## 6. Hero

Hero should be photography-first.

Desired desktop composition:
- large headline;
- concise supporting text;
- one primary CTA;
- one secondary "view projects" action;
- large interior image occupying approximately 50–65% of visual weight.

Do not put the hero content inside a generic white card.

Do not add:
- ratings;
- fake client counts;
- icon benefits;
- badges;
- multiple pricing claims.

The first screen should breathe.

## 7. Photography

Photography is the primary premium signal.

Preferred subjects:
- modern kitchens;
- built-in cabinetry;
- wardrobes;
- wood details;
- stone surfaces;
- joints, hardware and material close-ups;
- furniture shown in real spatial context.

Avoid:
- generic stock photos of workers holding tools;
- isolated product cut-outs;
- obvious AI geometry errors;
- repetitive images that do not add information.

Prefer a small number of strong images over many mediocre ones.

## 8. Selected Projects layout

Use an editorial/asymmetric composition.

Project presentation should feel more like an interior magazine than a gallery of cards.

Possible pattern:
- one large image;
- one smaller counter-positioned image;
- large project number;
- small category label;
- short project title and description.

On mobile, prioritize clarity over preserving desktop asymmetry.

## 9. What We Make

Do not use four equal cards.

Preferred direction:
- numbered category list;
- large typography;
- image paired with currently highlighted category;
- subtle hover/focus behavior if appropriate.

If interactive image switching is too complex for the current stage, use a static editorial grid instead.

## 10. Process

Keep it structured and quiet.

Preferred ingredients:
- numbered steps;
- thin separators;
- generous vertical spacing;
- no cartoon icons;
- no elevated cards unless there is a strong design reason.

## 11. Materials section

Should feel tactile.

Use:
- macro photography;
- material fragments;
- texture;
- detail compositions.

Possible visual rhythm:
- large image;
- small supporting crop;
- short text labels;
- wide margins.

## 12. Motion

Motion must be restrained.

Allowed direction:
- subtle image reveal;
- gentle text entrance;
- hover transitions;
- smooth anchor scrolling;
- very light parallax only if it remains performant.

Do not add:
- site-wide horizontal scroll;
- WebGL;
- heavy page transitions;
- motion libraries just for decoration;
- animations that block interaction.

## 13. Mobile

Mobile must be designed intentionally.

Recommended hero order:
1. headline;
2. supporting copy;
3. CTA;
4. image.

Projects should become a vertical editorial sequence.

Do not force desktop asymmetry onto narrow screens.

No horizontal overflow.

## 14. Portfolio presentation principle

The final page should look good in:
- full-page desktop screenshot;
- 16:9 portfolio crop;
- mobile screenshot.

Important sections should still read well when cropped for Kwork portfolio images.

## 15. "Do not" summary

Do not:
- clone a reference;
- use fake testimonials;
- use fake ratings;
- use fake metrics;
- use generic SaaS visuals;
- use too many cards;
- use bright blue as a default business accent;
- make mobile an afterthought;
- over-animate;
- sacrifice usability for visual novelty.
